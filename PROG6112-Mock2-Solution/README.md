# PROG6112 Exam-Level Mock 2 – Model Solution

One repo, one branch, one folder per question (the same layout to use in the real exam).

| Folder | Project | Run | Expected result |
| --- | --- | --- | --- |
| `Question1/` | Farm stall sales report | `VaalFreshProduce.java` | Total 1465, average 122, top product Potatoes |
| `Question2/` | Vaal Car Hire GUI | `CarHireForm.java` (set as the main class in `pom.xml`) | Thabo Nkosi, Sedan, 7 days → R 3150.00, saved to `rental.txt` |

Open each folder separately in NetBeans (**File → Open Project**). `CarHireForm` has its `.form` file, so it opens in **Design** view.

Unit tests are in each project's `src/test/java`. Right-click the project → **Test**.
